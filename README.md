# ai-engineering

  Learning to build products on top of pre-trained AI models.

  Each folder has notes and a working example.

  ## Topics

  **Foundations**

  - 01 — LLMs — predicts the next token, over and over
  - 02 — Prompt Engineering — the instructions behind every call
  - 03 — Structured Output — typed data instead of prose
  - 04 — Context Engineering — deciding what fills the window

  **Giving It Actions**                                                

  - 05 — Tool Use — functions the model can call
  - 06 — Agents — the model chooses its own steps

  **Giving It Knowledge**

  - 07 — Retrieval — search your data, then answer                     
  - 08 — Memory — what survives between calls

  **Drawing the Line**

  - 09 — AI System Design — where the model ends, code begins
  - 10 — Prompt Injection — hostile instructions hiding in input
  - 11 — Guardrails — checks the model can't talk past

  **Knowing It Works**
                                                                       
  - 12 — Evals — scoring changes instead of guessing
  - 13 — Observability — seeing what the model actually did
